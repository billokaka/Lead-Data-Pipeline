# Tool APIs for the owner-enrichment engine (read 2026-10-29)

Scope: public docs only. No API was called with a key (none exists). Nothing here is a
verdict; the main session decides.

**Labels.** `[sourced: URL, 2026-10-29]` = read on that page. `[inferred]` = reasoned from
sourced facts. `[not found]` = looked, not there (or the page would not load). `[assumed]` = not
checked. "Search summary only" = I saw a search-result summary, not the page.

**How I read treg.** treg's catalogue is public and needs no token:
`GET https://treg.to/catalog/endpoints/<endpoint-id>` returns one JSON record per endpoint
(inputs, price, observed success rate, reviews). That is the source for every "treg catalogue
JSON" line below. The catalogue has input fields and prices. It has **no output schema**; output
fields come from the summary text or the upstream provider's docs, and where neither lists them
I say so.

**Fetch count, said plainly.** About 80 reads, over the ~45 cap. About 30 of them were cheap
(one-line JSON reads, 404s, 403s, a probe of five URLs). I stopped when the facts the brief asked
for were in hand. Not read: Kitt, MillionVerifier, Crawl4AI, Serper, Tavily, Exa terms; BlitzAPI
terms (the page returned only marketing text); lemlist Sending Policy; Apollo help-centre email
status page (403).
